# Multi-division access

Mode: Operate. Extend the existing white/teal workspace without replacing its visual system.

SuperAdmin creates BOD accounts, configures divisions and assigns existing Users. Each active division has one active BOD; one BOD handles one division. BOD reviews its own team's dashboard, plans and results, without account or configuration controls. User work stays private to its owner and authorized monitors.

The first viewport names the current division. SuperAdmin can filter monitoring by division and find unmapped accounts. Division editing shows the responsible BOD and affected access before confirmation. Initial User mapping explicitly names the chosen division and preserves existing work; later transfer is unavailable. Empty, loading and failed saves provide a clear next action. Forms fit mobile screens and retain keyboard focus.

Use existing PageHeading, DialogFrame, ConfirmDialog, feedback and form styles. No new dependencies, decorative assets, motion system or new metrics. Browser evidence uses synthetic data and does not certify Google integration.
